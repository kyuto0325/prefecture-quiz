# 🗾 都道府県クイズ

子ども向けに、日本の47都道府県について楽しく学べるクイズアプリです。

Pythonの学習と、Git / GitHubを使った開発経験を積むことを目的として制作しています。

## 🎯 このアプリについて

都道府県に関する問題が出題され、選択肢から答えを選ぶクイズゲームです。

遊びながら、

- 都道府県の名前
- 県庁所在地
- 名産品
- 有名な観光地
- 都道府県に関する豆知識

などを学べるアプリを目指しています。

## 🎮 実装予定の機能

- [ ] 4択クイズ
- [ ] 問題のランダム出題
- [ ] 10問チャレンジ
- [ ] 正解・不正解の判定
- [ ] 問題ごとの解説
- [ ] 最終スコアの表示
- [ ] 難易度選択
- [ ] ジャンル選択
- [ ] Webブラウザで遊べるようにする

## 🛠 使用技術

- Python
- Git
- GitHub

今後、Webアプリ化する際にStreamlitなどの利用も検討しています。

## 🗾 日本一周旅行モード

47都道府県を旅しながらクイズに挑戦するモードです。

各都道府県でクイズに正解すると次の地域へ進むことができます。

### 実装予定

- [ ] 47都道府県を順番に旅する
- [ ] 都道府県ごとのクイズ
- [ ] クリア時にご当地スタンプを獲得
- [ ] 名産品や観光地の豆知識を表示
- [ ] 現在地を表示
- [ ] 旅行の進捗率を表示
- [ ] 47都道府県制覇画面
- [ ] 地方編

を実際に作品を作りながら学ぶことを目標としています。
