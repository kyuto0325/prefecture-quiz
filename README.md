# 🗾 都道府県クイズ

子ども向けに、日本の47都道府県について楽しく学べるクイズアプリです。

Pythonの学習と、Git / GitHubを使った開発経験を積むことを目的として制作しています。

**最終更新：2026年9月12日**

---

## 🎯 このアプリについて

都道府県に関する問題が出題され、4つの選択肢から答えを選ぶクイズゲームです。

遊びながら、以下のような日本各地の特色を学べるアプリを目指しています。

- 🏔️ 地理・自然
- 🏯 歴史
- 📸 観光・名所
- 🍜 食・特産品
- 🎎 文化・伝統
- 🏭 産業・暮らし

小学生など、これから日本の地理に興味を持つ子どもでも楽しめるような問題作りを意識しています。

---

## 🎮 ゲームモード

現在、3つのゲームモードを用意しています。

### 🗾 都道府県選択

好きな都道府県を選んで挑戦する通常モードです。

- 都道府県を選択
- 難易度を選択
- カテゴリを選択
- 5問 / 10問から出題数を選択
- 問題・選択肢はランダムに出題
- 正答率80%以上で合格

### 🏆 地方制覇の旅

地方に含まれる都道府県の問題からランダムに出題されるチャレンジモードです。

現在は**近畿地方**に対応しています。

- 近畿7府県・210問から30問をランダム出題
- 30問全問正解で「近畿地方制覇」
- 制覇できなかった場合は、あと何問正解すればよかったかを表示

### 🇯🇵 日本一周制覇の旅

47都道府県すべての問題から挑戦する高難度モードです。

**現在開発中です。**

将来的には50問・100問などのコースを用意し、全問正解で「日本一周制覇」とする予定です。

## ⭐ 難易度

問題は3段階の難易度に分けています。

### ⭐ Level 1：はじめて

一般教養レベルの問題です。

県庁所在地、有名な観光地、食べ物など、子どもでも聞いたことがあるような内容を中心に出題します。

### ⭐⭐ Level 2：ものしり

少し知識が必要な問題です。

その都道府県について学ぶことで分かるような、地理・歴史・産業などの内容を中心に出題します。

### ⭐⭐⭐ Level 3：ご当地博士

より詳しい知識が必要な問題です。

地域の歴史、伝統文化、特産品、産業など、一歩踏み込んだ内容を出題します。

```text

│
├── main.py
│
├── questions/

│   ├── kyoto.py
│   ├── osaka.py

│   ├── nara.py

│   └── mie.py
│
```

`main.py` にはクイズを動かす処理を書き、`questions` フォルダには各都道府県の問題データを保存しています。

問題データとクイズの処理を別ファイルに分けることで、都道府県を追加しやすい構成を目指しています。

## 📚 このプロジェクトの目的

このプロジェクトでは、完成したアプリを作ることだけではなく、

- Pythonによるプログラミング
- Gitによるバージョン管理
- GitHubを使った開発
- データと処理を分離したプログラム設計
- アプリケーション設計
- 機能を少しずつ追加していく開発方法

を、実際に作品を作りながら学ぶことを目標としています。

少しずつ機能と問題データを追加しながら、47都道府県すべてに対応したクイズアプリの完成を目指します。
